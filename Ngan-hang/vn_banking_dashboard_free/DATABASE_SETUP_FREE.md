# Database setup (free tier)

## Recommended database

Use Neon Free PostgreSQL rather than Render Free PostgreSQL for the long-lived dashboard database.

- Neon Free currently includes 1 GB storage per project, 100 CU-hours/month and 5 GB public network transfer/month.
- Neon compute scales to zero after 5 minutes of inactivity.
- Render Free Postgres expires after 30 days and has no backups; do not use it as the only durable store for verified financial observations.
- Free tiers are suitable for a small pilot, not a production SLA. Export CSV backups regularly.

## Configure Neon

1. Create a Neon account and a new PostgreSQL project.
2. Create/use the default database.
3. Copy the pooled connection string from the Neon dashboard. Keep it private. It should start with `postgresql://` and include `sslmode=require`.
4. In Render > `minhtriinvest-banking-api` > Environment, add:
   - `DATABASE_URL`: the Neon connection string.
   - `BANKING_WRITE_KEY`: a long random secret generated by a password manager (at least 32 random characters).
   - `CORS_ORIGINS`: `https://minhtriinvest-banking-dashboard.onrender.com`
5. Save changes and wait for the API service to redeploy.
6. Test `https://minhtriinvest-banking-api.onrender.com/health`; it should return `status: ok` and `database: connected`.

The backend normalizes Neon `postgresql://` URLs to the installed psycopg v3 driver. Never commit database URLs or write keys to GitHub or the public frontend.

## Import the initial data

From the public dashboard's Data Management section, use Server Import in this order:

1. `BANK_REGISTRY_STARTER.csv` (registry rows remain `needs_verification`; this is a starter list, not a verified listing universe).
2. `BIDV_CONSOLIDATED_FY2023_FY2025_VERIFIED.csv`.
3. `CTG_CONSOLIDATED_Q3_2026_VERIFIED.csv`.

When prompted, enter the `BANKING_WRITE_KEY`. The browser prompt does not save it. Do not import staging/review files as verified data.

## Security and operating notes

- Read endpoints are public; write/import endpoints require `X-API-Key`.
- Keep the write key only in Render environment variables and your password manager.
- Do not use the API's default SQLite database for production data: Render Free web services have ephemeral filesystems.
- Free Render web services spin down after 15 minutes idle; the first request after idle can take about a minute.
- Export verified CSVs regularly. Neon Free has usage limits and no production uptime SLA.
